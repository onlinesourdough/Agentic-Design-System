# resources.onlinesourdough Course Library

This design-only direction resets Resources to a warm, folder-first course library that sits close to [onlinesourdough.com](https://onlinesourdough.com). Home starts with the sidebar collapsed on desktop, then routes into one of four restrained monochrome folder stages. The folders carry the paid 01–08 Blueprint, while Free companions and Kits stay first-class destinations in the richer sidebar.

The preview includes a useful orientation block with a product-specific video frame, concrete outcome, Free/Paid cues, and one action. It also proves folder routing, browser history, Search, My tasks/progress, optional Favorites, Blueprint hierarchy, Free companions, Kits, Account, Help, reader/access states, and persistent light/dark themes at desktop and mobile sizes.

## Files

- `DESIGN.md`: portable tokens, composition fingerprint, IA, reference boundaries, and implementation guidance.
- `index.html`: static responsive preview with hash-routed Home, stages, readers, tasks, account, help, and search.
- `assets/resources-folder-transparent.png`: existing original archive-folder pixel asset, filtered into a warm-monochrome orientation frame only.
- `assets/fonts/`: self-hosted Geist Sans, Geist Mono, Geist Pixel Square, and license.

No application code, integrations, external URLs, deployments, commits, or pushes are part of this example reset.
