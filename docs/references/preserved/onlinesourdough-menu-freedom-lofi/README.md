# onlinesourdough Menu: Same Bake Direction

This design-only preview keeps the approved onlinesourdough low-fi books, shelves, images, interactions, responsive behavior, colors, and light/dark themes. A code-native sourdough boule now sits beside the lowercase wordmark in both pages and acts as the favicon. The selected version returns to the recognisable filled silhouette: 54 large, tightly spaced modules on a wide 10×7 grid create a low dome, rounded base, and three continuous negative score cuts. Each square occupies 82% of its cell, preserving the larger Arc’It pixel weight without the facial expression created by the outline experiment. Black and white lockups use the same 44×34-pixel mark size. Header, offer field, About sections, and footer now share Arc’It’s 1240-pixel desktop shell, while headlines and paragraphs keep their narrower reading measures inside it. It loads as a normal SVG image rather than a fragile CSS mask. Geist Pixel carries the hero, manifesto, About introduction, and About headings while paragraphs remain smooth and readable. The centered Offers switcher opens directly into `Done for you` and `DIY + done with you`. `Menu` anchors to the offer menu; header `About` scrolls to the inline manifesto, whose CTA opens the dedicated About page using the live site’s current copy. Anchor navigation works normally, while a browser reload deliberately returns to the hero instead of restoring Menu or About. All viewports use natural scrolling; no snap or wheel locking remains. Both pages close with a shared ecosystem footer linking `gustavonline ↗` and `Arc'IT AI ↗`.
