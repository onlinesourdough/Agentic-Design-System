# ADS design collection

`workspace/designs/` is the one persistent collection for every ADS direction.
Each selected slug contains its canonical portable `DESIGN.md`, resolved brief,
local preview, optional companions, and any design-local run, review, state, or
handoff evidence. A selected direction is never silently replaced by another.

The four pre-existing showcase directions remain deliberately curated, marked
by their local `proof.json`. Other collection entries are selected work or
immutable handoff evidence, not implicit promotions. A cross-owner delivery
creates a design-local `handoffs/<name>/HANDOFF.md`; receiver acceptance stays
separate.
