# Curated operations workspace

This curated ADS example organizes a working operations surface around a real
decision, explicit status, and useful interaction states. Its brief, portable
design direction, local preview, and review proof travel together.

`DESIGN.md` remains the canonical visual direction. Any receiving application
accepts a versioned `HANDOFF.md` snapshot and then owns application behavior,
data, and implementation; optional preview or token files never replace the
direction.
