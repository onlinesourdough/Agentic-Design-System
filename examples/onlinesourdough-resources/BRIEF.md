# Brief — resources.onlinesourdough

- **Need:** Give founders and small teams a calm, navigable place to choose the
  next business decision, then find the course, reusable foundation, or project
  context that supports it.
- **Audience:** People who are deciding what to change around business,
  software, AI, and ownership; they are not browsing a generic course
  marketplace.
- **Desired action:** Start with `Begin`, then open the most relevant library
  area or the next Blueprint step.
- **Current constraint:** The four-part information architecture and revised
  sidebar behavior are right, but the latest preview changed too much of the
  stronger historical Resources direction. Restore the earlier grid, hero,
  compact folder, and VSL rhythm while keeping the newer navigation model. The
  transparent folder shelf should sit lower so it supports rather than bisects
  the folders.
- **Required content:** The locked Explore, Open Source, Courses, and Projects
  IA; four top-level folders; a useful orientation/VSL surface; a restrained
  right-side reading column; Search, Newsletter, Log in, and theme actions; one
  Course page; one honest internal Project page; Account and Need help pages.
- **Required routes/states:** Explore landing, Open Source landing, the
  Business Architecture course with ordered Blueprint steps, an internal AIOS
  Desktop project page, global Search with loading/results/empty states,
  expanded and collapsed desktop sidebar, mobile drawer, light/dark themes,
  hover, active, visible focus, validation/error, success, paid/permission, and
  offline guidance.
- **Constraints:** Warm Online Sourdough cream/brown palette; Geist Pixel,
  Geist Sans, and Geist Mono; exact supplied Resources pixel-folder asset; no
  invented public GitHub URLs; no application code, integrations, secrets,
  deployments, or edits to the read-only source repository.
- **Proof:** At roughly 1440×1000 and 390×844, a first-time visitor can identify
  the four areas, reach Begin, understand the sidebar hierarchy, collapse and
  reopen desktop navigation, open Search, and use the same content in light and
  dark mode without horizontal overflow.
- **Receiving project or repository:** The project selected to implement the
  accepted design; this example remains a portable design workbench artifact
  until accepted.
